# Sistema-Reclamos-Tino

Sistema de Reclamos: diseño arquitectónico, diseño externo (prototipos) y la
aplicación Java que los implementa.

## Contenido del repositorio

| Archivo / carpeta | Qué es |
|---|---|
| `app/` | Aplicación de escritorio en Java 21 + Swing. Ver [`app/README.md`](app/README.md) |
| `Teoria/TinoPrototipos_menu_con_iconos.xlsm` | Prototipos de pantalla y menú de módulos |
| `Teoria/LIBRO DISEÑO-BD.pdf` | Diseño de la base de datos |
| `Teoria/entregable 1 sistema de reclamos.docx.pdf` | Primer entregable del sistema |

## Arranque rápido

```bash
cd app
mvn compile exec:java
```
